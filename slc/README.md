# 🏰 SECRET LAB: CUBED (SLC)

<p align="center">
  <b>Комплексный оркестратор раундов SCP: Secret Laboratory в Minecraft 1.20.1 Forge</b><br>
  <i>Round Engine, Role Assignment, CASSIE Voice Announcer, SCP-939 Mimicry, Alpha Warhead, and LCZ Decontamination</i>
</p>

---

## 🌟 Интеграция в общую экосистему:

SLC объединяет все разработанные моды в единую соревновательную игру:
1. **0-7-9 (`zero_seven_nine`)** — Игрок с ролью `SCP-079` получает камеры, тактическую карту TAB, управление дверьми и энергией AP.
2. **Light Enchanted (`lightenchanted`)** — Световая атмосфера STR 2.0, аварийные прожекторы, затемнения `[F] BLACKOUT` и стробоскопы.
3. **Snow - SCPied (`snow_scpied`)** — Физические следы шагов (Footprints) и брызги крови (Blood Decals) при ранениях и побегах на Поверхности.
4. **TACZ (Timeless and Classics Zero)** — Огнестрельное оружие для МОГ, Охраны и Хаоса.
5. **Simple Voice Chat (SVC)** — Живая голосовая связь по рациям и захват голосов для мимикрии **SCP-939**.

---

## 🎮 Команды управления:
- `/slc countdown` — Запуск 15-секундного таймера до начала раунда.
- `/slc start` — Мгновенный принудительный старт раунда с распределением ролей.
- `/slc role <player> <ROLE>` — Назначение роли игроку (`CLASS_D`, `SCIENTIST`, `FACILITY_GUARD`, `SCP_079`, `SCP_939`, `SCP_173`, `SCP_049`, `SCP_096`, `MTF_COMMANDER`, `CHAOS_MARAUDER`).
- `/slc cassie <message>` — Синтез и глобальная трансляция голосового оповещения CASSIE.
- `/slc warhead <start|cancel>` — Управление детонацией Альфа-Боеголовки (Alpha Warhead).
