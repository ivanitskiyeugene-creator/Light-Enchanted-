**Light Enchanted** — мод для создания атмосферного киношного освещения в Minecraft. 
Ставь прожекторы, динамические поворотные сценические головы, направляй свет в **любую точку мира** (вниз, горизонтально, сквозь проемы и окна), настраивай любой цвет и форму через удобный визуальный редактор, и получай **настоящие объемные лучи света (God Rays)**, пробивающиеся сквозь решетки, вентиляторы и зеркала.

---

## ✨ Главные возможности

### 🤖 Поворотный сценический прожектор (Moving Head Spotlight)
- Автоматически покачивается и плавно сканирует пространство по осям Yaw и Pitch.
- Динамически перемещает луч и проецирует движущиеся световые пятна и тени на стенах и полу.
- Переключение скорости и угла сканирования кликом ПКМ.

### 🌀 Вентиляция SCP Containment и настенные кулеры
- **SCP HCZ 3x3 Industrial Fan:** Тяжелый монолитный промышленный вентилятор в темном матовом оружейном металле (без белых полос). Вращающиеся лопасти, защитная решетка, звуковые эффекты.
- **1x1 Compact Wall Fan:** Компактный настенный вентилятор с 4-лопастной крыльчаткой, переключением скоростей (Выкл / Медленно / Средне / Турбо) и сквозной трассировкой теней.

### 🔦 Наведение в любую точку мира (3D Aiming)
- **Предмет «Тюнер луча»:** кликни по излучателю, затем кликни по нужной точке мира или **прицелься вдаль по воздуху** (дальность до 128 блоков).
- **Кнопка «Цель из прицела»:** мгновенно ставит цель в блок, на который ты смотришь.

### 🌫️ STR 2.0: Микро-трассировка теней и объемные лучи (Micro-RT God Rays)
- **Дискретный луч STR 2.0:** массив микро-лучей с честным воксельным шагом сканирует любые препятствия («нету — дальше, есть — остановиться»).
- **6-осевая адаптивная проекция:** четкое световое пятно идеально ложится на пол, стены и потолок без артефактов и скосов.
- **Отражение от оптических зеркал** и **фильтрация цвета** через витражные стекла в реальном времени.

### 🎨 Живой визуальный редактор (In-Game GUI)
ПКМ пустой рукой по излучателю открывает редактор с **мгновенным живым предпросмотром**:
- **Цвет:** отдельные RGB-слайдеры, ввод HEX-кода (`#FFB347`) и режим плавной цикличной **«Радуги»**.
- **Геометрия:** ширина, разброс конуса, высота, свечение, пульсация и скорость вращения.
- **Формы луча:** Прожектор, Цилиндр, Классика, Спираль, Плоскость, Звезда, Пирамида, Овал, Щель.

### 💡 Реальный свет в точке попадания (Block Light 15)
- В точке падения луча на поверхность сервер автоматически размещает невидимый источник света **15-го уровня**.

## 🎮 Управление и быстрый старт

| Действие | Результат |
| --- | --- |
| **ПКМ пустой рукой** по излучателю | Открыть редактор луча |
| **ПКМ по настенному/SCP вентилятору** | Переключение скорости вращения (Выкл / Мин / Сред / Макс) |
| **ПКМ по поворотному прожектору** | Смена режима покачивания |
| **ПКМ Тюнером** по излучателю | Привязать тюнер к этому излучателю |
| **ПКМ Тюнером** по блоку / воздуху | Установить точку падения луча |
| **Shift + ПКМ Тюнером** по воздуху | Сбросить привязку тюнера |
| **Shift + ПКМ Тюнером** по излучателю | Сбросить цель луча |
