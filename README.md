**Light Enchanted** — мод для создания атмосферного киношного освещения в Minecraft. 
Ставь прожекторы, направляй свет в **любую точку мира** (вниз, горизонтально, сквозь проемы и окна), настраивай любой цвет и форму через удобный визуальный редактор, и получай **настоящие объемные лучи света (God Rays)**, пробивающиеся сквозь решетки, заборы и вентиляторы.

---

## ✨ Главные возможности

### 🔦 Наведение в любую точку мира (3D Aiming)
Забудь про скучные вертикальные столбы маяков. Луч направляется в **любую координату**:
- **Предмет «Тюнер луча»:** кликни по излучателю, затем кликни по нужной точке мира или **прицелься вдаль по воздуху** (дальность до 128 блоков).
- **Кнопка «Цель из прицела»:** мгновенно ставит цель в блок, на который ты смотришь.

---

### 🌫️ Микро-трассировка теней и объемные лучи (Micro-RT God Rays)
Встроенный геометрический трассировщик в реальном времени сканирует препятствия перед лучом:
- **Работает с ЛЮБЫМИ моделями:** ванильные решетки, заборы, ступеньки, а также **кастомные 3D-модели из модов** (промышленные вентиляторы, фигурные сетки, трубы, каркасы).
- Сплошной луч автоматически **«разрезается» на отдельные объемные пучки света (God Rays)**.
- На полу и стенах в точке падения проецируется **чёткий светотеневой силуэт** (проекция решетки или лопастей).

---

### 🎨 Живой визуальный редактор (In-Game GUI)
ПКМ пустой рукой по излучателю открывает редактор с **мгновенным живым предпросмотром**:
- **Цвет:** отдельные RGB-слайдеры, ввод HEX-кода (`#FFB347`) и режим плавной цикличной **«Радуги»**.
- **Геометрия:** ширина, разброс конуса, высота, свечение, пульсация и скорость вращения.
- **6 форм луча:** Прожектор (Cone), Лазер (Cylinder), Классика (Beacon Column), Спираль (Helix), Плоскость (Sheet), Звезда (Star).
- **Тумблер «Тени / Трафарет»:** мгновенное переключение режима теней.

---

### 💡 Реальный свет в точке попадания (Block Light 15)
Луч — это не просто визуальный эффект:
- В точке падения луча на поверхность сервер автоматически размещает невидимый источник света **15-го уровня**.
- Пол, стены, монстры и игроки в световом пятне **реально освещены**.
- Безопасное авто-удаление света при выключении луча или смене цели (без зависаний сохранения мира).

---

### 👻 Креативный невидимый излучатель (Для карт и построек)
`/give @s lightenchanted:light_emitter_creative`
- Невидимый блок без коллизии, сквозь который можно проходить.
- Виден «призрачным кубом» только когда в руке тюнер или сам блок.
- В редакторе доступны **слайдеры сдвига X/Y/Z (±8 блоков)** — блок можно спрятать глубоко внутри стены, потолка или светильника, а луч пустить из нужной точки в пространстве.

---

### 🌈 Совместимость с шейдерами (Iris, Oculus, OptiFine)
- Рендеринг построен на стандартном пайплайне `beaconBeam`.
- Полноценно поддерживаются шейдерпаки (**Complementary, BSL, SEUS, AstraLex, Solas** и др.) с объемным туманом, блюмом и постобработкой.
- На дальних дистанциях (>30-50 блоков) луч плавно и мягко растворяется в атмосфере.

## 🎮 Управление и быстрый старт

| Действие | Результат |
| --- | --- |
| **ПКМ пустой рукой** по излучателю | Открыть редактор луча |
| **Shift + ПКМ** по излучателю | Быстрое включение / выключение луча |
| **ПКМ Тюнером** по излучателю | Привязать тюнер к этому излучателю |
| **ПКМ Тюнером** по блоку / воздуху | Установить точку падения луча |
| **Shift + ПКМ Тюнером** по воздуху | Сбросить привязку тюнера |
| **Shift + ПКМ Тюнером** по излучателю | Сбросить цель луча (возврат к лучу вниз) |

```
[       ] [         ] [ Аметист ]
[       ] [ Железо  ] [         ]
[ Железо] [         ] [         ]
```
*(Тюнер подсвечивается зачарованным блеском, пока к нему привязан блок).*

## 📦 Установка

1. Установи **Minecraft 1.20.1** с загрузчиком **Forge (47.2.0 или новее)**.
2. Скачай готовый jar-файл из раздела [Releases](https://github.com/ivanitskiyeugene-creator/Light-Enchanted-/releases).
3. Помести файл `.jar` в папку `.minecraft/mods`.
4. Запускай игру и наслаждайся атмосферным светом!

---

## 🌐 Мультиплеер и производительность

- **Полная синхронизация:** все настройки и цели хранятся на сервере и автоматически рассылаются всем игрокам в радиусе видимости.
- **Оптимизация:** расчет теневой маски выполняется за доли миллисекунды и кэшируется — **0% просадки FPS** при статичном окружении.
