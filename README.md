# Light Enchanted

Мод для **Minecraft 1.20.1 (Forge 47.x)** — вручную настраиваемые лучи света.
Полностью кастомные цвета, формы и эффекты. Ванильный маяк ограничен цветом
стекла — этот мод рисует луч с нуля, поэтому доступен любой RGB-цвет и любая
геометрия.

## Возможности

- 💡 **Блок «Излучатель света»** — ставится как обычный блок, сам светится
  (уровень 15), луч идёт вверх из блока.
- 🎛️ **Редактор по ПКМ** с живым предпросмотром прямо в мире:
  - **Цвет**: слайдеры R/G/B, ввод HEX (`#67C7FF`), режим **«Радуга»**
    (плавный перебор спектра);
  - **Форма**: Классика, Цилиндр, Конус, Спираль, Плоскость, Звезда;
  - **Ширина** луча (0.05–2 блока) и **свечение** (внешняя оболочка);
  - **Высота** (2–160 блоков) или режим **«До неба»** (до лимита мира);
  - **Яркость** (прозрачность), **Пульсация**, **Вращение**.
- ⚡ **Shift + ПКМ** — быстрое включение/выключение луча без GUI.
- 🌐 Полная синхронизация в мультиплеере (клиент → сервер → всем игрокам),
  настройки сохраняются в чанке.
- 🛠️ Крафт: стекло + светокамень + осколок аметиста + железо
  (см. `data/lightenchanted/recipes/light_emitter.json`).

## Сборка

Нужен **JDK 17** и **Gradle 8.x** (обёртка не прилагается — см. ниже).

```bash
gradle build
```

Готовый jar: `build/libs/lightenchanted-<версия>.jar`.

Варианты, если Gradle не установлен:

1. **GitHub Actions** — в репозитории настроен workflow `Build Mod`:
   он собирает jar на каждый push, готовый файл забирается из артефактов
   сборки (`lightenchanted-jar`).
2. Скопируй `gradlew`, `gradlew.bat` и папку `gradle/` из официального
   Forge MDK 1.20.1 — после этого можно собирать через `./gradlew build`.

> Первая сборка долгая: ForgeGradle скачивает и декомпилирует Minecraft.

## Установка

1. Установи **Forge 1.20.1 (47.x)** в лаунчер.
2. Положи собранный jar в папку `mods`.
3. Запусти игру, найди «Излучатель света» во вкладке **Light Enchanted**
   или скрафти его.

## Использование

| Действие | Результат |
| --- | --- |
| ПКМ по излучателю | Открыть редактор луча |
| Shift + ПКМ | Вкл/выкл луч |

Все изменения в редакторе видны сразу (живой предпросмотр). «Применить»
отправляет настройки на сервер, не закрывая окно; «Готово»/Esc — отправляет
и закрывает.

## Структура проекта

```
src/main/java/dev/lightenchanted/
├── LightEnchanted.java            # точка входа
├── beam/                          # BeamConfig (параметры луча), BeamShape
├── block/, blockentity/           # блок-излучатель и его данные
├── network/                       # пакеты клиент→сервер
├── client/render/                 # рендерер луча (все 6 форм)
├── client/gui/                    # экран редактора
└── init/                          # регистрация блоков/предметов/вкладки
tools/generate_textures.py         # генератор текстур (без зависимостей)
```

## Известные ограничения

- Луч — визуальный: он не освещает блоки вдоль столба. Светит сам блок
  (уровень 15).
- Совместимость с шейдерами (OptiFine/Iris/Oculus + Rubidium) не гарантирована:
  они могут переопределять рендер-тайп луча.

## Планы (roadmap)

- Горизонтальные лучи (ориентация блока в 6 сторон).
- Реальное динамическое освещение вдоль луча (через lighting-ядро).
- Частицы внутри луча, звуковая аура.
- Пресеты цветов и копирование настроек между излучателями.
- Мини-режим «лазера» с точным прицелом на блок.
