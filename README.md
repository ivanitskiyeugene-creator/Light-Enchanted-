# Light Enchanted

Мод для **Minecraft 1.20.1 (Forge 47.x)** — вручную настраиваемые лучи света.
Ставишь блок, настраиваешь цвет, указываешь точку назначения — и получаешь
направленный световой поток (прожектор, god ray) для атмосферных построек.
Любой RGB-цвет, любая форма, любое направление. Луч — визуальная модель
(без реального освещения; тени и динамический свет — в планах).

## Как это работает

1. **Поставь «Излучатель света»** — блок светится (уровень 15). По умолчанию
   луч — «Прожектор», направлен **вниз** (переключается в редакторе).
2. **Настрой цвет и форму** — ПКМ пустой рукой по излучателю: редактор
   с живым предпросмотром (RGB + HEX, «Радуга», 6 форм, ширина, разброс,
   свечение, яркость, пульсация, вращение).
3. **Укажи точку назначения** — двумя способами:
   - предмет **«Тюнер луча»**: ПКМ по излучателю → ПКМ по нужной точке в мире
     (до 128 блоков);
   - кнопка **«Цель из прицела»** в редакторе — цель ставится туда, куда
     ты смотришь.
4. Луч тянется к точке в **любом направлении**: вниз, вверх, горизонтально,
   по диагонали, сквозь проёмы. Цель можно сбросить — тогда луч идёт
   вниз/вверх на заданную высоту.

**Shift + ПКМ** по излучателю — быстрое вкл/выкл луча.

### Креативный (невидимый) излучатель

`/give @s lightenchanted:light_emitter_creative` — невидимый блок без
коллизии для карт и построек. Особенности:

- ничего не роняет, крафта нет (creative-only);
- виден «призрачным» кубом, пока в руке тюнер или сам этот блок;
- в редакторе доступны **слайдеры сдвига X/Y/Z** (±8 блоков) — луч
  рендерится из смещённой точки, а сам блок можно спрятать внутри стены
  или светильника.

## Рендер

Луч рисуется аддитивно (накопление света): центральное ядро горячее,
края мягко растворяются, пересекающиеся лучи складываются по яркости.
Мягкие световые пятна рисуются на источнике и в точке попадания.

## Формы

| Форма | Смысл при наведении на цель |
| --- | --- |
| Прожектор | Узкий конус у блока → широкий у цели (параметр «Разброс»). Основной «киношный» вид |
| Лазер | Ровный тонкий луч постоянного диаметра |
| Классика | Квадратный столб, как у маяка |
| Спираль | Две ленты, закрученные вокруг оси луча |
| Плоскость | Стена света (хороша для «щелей» и занавесов) |
| Звезда | Четыре скрещённых плоскости, можно вращать |

Светящиеся точки рисуются на источнике и в месте попадания луча — как пятно
света на поверхности.

## Предметы

- **Излучатель света** — крафт: стекло + светокамень + осколок аметиста +
  железо (`data/lightenchanted/recipes/light_emitter.json`).
- **Тюнер луча** — крафт: осколок аметиста + железный слиток по диагонали
  (подсвечивается чарами, пока к нему привязан излучатель).

## Сборка

Нужен **JDK 17** и **Gradle 8.x**:

```bash
gradle build
```

Готовый jar: `build/libs/lightenchanted-<версия>.jar`.

Варианты, если Gradle не установлен:

1. **GitHub Actions** — workflow `Build Mod` собирает jar на каждый push,
   забирай артефакт `lightenchanted-jar` из вкладки Actions.
2. Скопируй `gradlew`, `gradlew.bat` и папку `gradle/` из официального
   Forge MDK 1.20.1 → `./gradlew build`.

> Первая сборка долгая: ForgeGradle скачивает и декомпилирует Minecraft.

## Установка

1. Установи **Forge 1.20.1 (47.x)**.
2. Положи jar в папку `mods`.
3. «Излучатель света» и «Тюнер луча» — во вкладке **Light Enchanted**.

## Мультиплеер

Все настройки (цвет, форма, цель) хранятся в блоке на сервере и рассылаются
игрокам автоматически. Пакеты от клиента проверяются на расстояние до блока.

## Известные ограничения

- Луч — визуальная модель: не освещает блоки и не отбрасывает настоящих теней
  («тени» как на референсе — это следующий этап, см. роадмап).
- Совместимость с шейдерами (Iris/OptiFine) не гарантирована.
- Один луч на излучатель (мультилучи — дальше по роадмапу).

## Планы (roadmap)

- 🌑 **Тени / фейковые god rays через решётки** — проекция «окна» на плоскость
  за лучом, имитация объёмного света через маску (как на скриншоте-референсе).
- Реальное динамическое освещение вдоль луча.
- Несколько лучей на один излучатель.
- Частицы (пыль в луче), звуковая аура прожектора.
- Пресеты цветов, копирование настроек между излучателями.
